# Projeto1 EBAC - Calculadora
Projeto de construção de uma simples Calculadora em Python

# Execução do script no terminal do Ubuntu (Linux):

## Passos para a execução.
1. Abrir o terminal
2. Navegue a até o diretório (pasta), onde o projeto está armazenado.
3. Conceda a permissão de execução do arquivo:

```bash
chmod 744 calculadora2.sh
```
4. Execute o script:
```bash
./calculadora2.sh
```
# Explicando o Código Python

O código python apresentado, foi desenvolvido para executar a funcionalidade de um simples calculadora. Onde o sistema executa as seguintes funções:
* Solicita que o usuário insira dois números;
* Solicita ao usuário a informação de qual operação aritmética o mesmo deseja realizar (soma, subtração, multiplicação ou divisão)
* Com base nas informações inseridas pelo usuário o código retornará com o resultado da operação.

### Exemplo:
```bash
Digite o primeiro número: 15
Digite o segundo número: 16
Digite a operação (+, -, *, /): *
O resultado da multiplicação é: 240.0
```
